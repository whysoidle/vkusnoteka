# Формат recipes.json

UTF-8 JSON, версия схемы 1. Основной файл содержит только рецепты и версии записей — без паролей, токенов, адреса сервиса и идентификатора текущего устройства в настройках.

```json
{
  "schemaVersion": 1,
  "records": [
    {
      "id": "uuid-рецепта",
      "modifiedAt": "2026-10-08T18:00:00.000Z",
      "clock": {"uuid-устройства": 1},
      "deleted": false,
      "recipe": {
        "id": "uuid-рецепта",
        "title": "Сырники",
        "category": "Завтраки",
        "ingredients": ["Творог — 400 г", "Яйцо — 1 шт."],
        "steps": ["Смешайте ингредиенты.", "Обжарьте с двух сторон."],
        "servings": "2 порции",
        "time": "20 минут",
        "notes": "",
        "sourceUrl": "https://example.com/recipe",
        "sourceText": "",
        "favorite": false,
        "draft": false
      }
    }
  ]
}
```

`clock` — вектор версий: при каждой локальной правке счётчик текущего устройства увеличивается. Вектор, который включает все счётчики другого и хотя бы один больший, является более поздней версией. Несравнимые векторы означают независимые изменения.

Удалённая запись сохраняет `id`, `modifiedAt`, `clock`, а `deleted` становится `true` и `recipe` — `null`. Эти записи нельзя удалять без координации всех устройств.

При конфликте используются детерминированный выбор основной версии и отдельная карточка с ID `<original-id>:conflict:<content-hash>`. Часы версий объединяются покомпонентным максимумом. Один и тот же конфликт не создаёт новую копию при каждом обмене. Исходные ссылки сохраняются в обеих карточках.

Файл сохраняется через `.pending` и `.bak`: полностью записанный временный файл заменяет основной. При повреждении/прерванной записи приложение проверяет оставшийся временный файл и резервную копию. При неизвестной версии схемы файл не заменяется пустой книгой.

Перенос базы выполняйте через импорт/экспорт или синхронизацию. Редактирование JSON вручную без изменения вектора версий может создавать неоднозначные конфликты.

## Поля карточки с версии 0.3.0

`photo` — миниатюра JPEG в Base64, до 120 КБ до кодирования; `tags` и `collections` — списки строк. Все поля необязательны для старых записей. Они входят в хеш карточки и синхронизируются в том же `recipes.json`. При использовании фото и тегов обновите оба приложения до 0.3.0, чтобы старый редактор не удалял неизвестные ему поля.
