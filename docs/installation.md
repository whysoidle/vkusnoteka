# Установка и обновление

Откройте [последний выпуск](https://github.com/whysoidle/vkusnoteka/releases/latest) и выберите файл для своей системы. Файлы приложения находятся в разделе **Assets** под описанием выпуска.

## Android

1. Скачайте `Vkusnoteka-Android-1.0.8.apk` на телефон.
2. Откройте файл. Если Android попросит разрешить установку из выбранного браузера или файлового менеджера, подтвердите разрешение.
3. Завершите установку и откройте Вкуснотеку.

Для обновления установите новый APK поверх предыдущего. У APK этого выпуска та же подпись, что у предыдущих личных сборок. Не удаляйте старое приложение перед обновлением: удаление может стереть локальные данные.

Приложение работает на Android 7+. Для локального ИИ нужны Android 8+ и процессор ARM64. APK занимает около 160 МБ; отдельно скачанная модель — ещё 977 МБ. Вместе это около 1,14 ГБ без фотографий каталога и системных данных.

## Windows

Скачайте `Vkusnoteka-Windows-1.0.8-Setup.exe` и запустите установщик. Приложение устанавливается для текущего пользователя.

Если установка не нужна, скачайте `Vkusnoteka-Windows-1.0.8-Portable.zip`, распакуйте архив целиком и запустите `recipe_vault.exe`. Файл EXE должен оставаться рядом с папками и библиотеками из архива. Portable означает запуск без установщика; база и настройки всё равно хранятся в папке данных пользователя, а не внутри ZIP.

Сборка предназначена для Windows 10/11 x64. Для локального ИИ нужны Windows 10 версии 1903 или новее либо Windows 11; рекомендуется от 8 ГБ оперативной памяти. Модель скачивается отдельно и занимает 2,50 ГБ. Для приложения и загрузки модели оставьте хотя бы 3,5 ГБ свободного места.

При обновлении закройте Вкуснотеку и запустите новый установщик. Для portable-версии распакуйте новый архив в отдельную папку целиком.

## macOS

1. Скачайте `Vkusnoteka-macOS-1.0.8.dmg` и откройте его.
2. Перетащите «Вкуснотека» в **Applications** («Программы»).
3. Запустите приложение из этой папки.

Для обновления сначала закройте приложение, затем замените его новой копией. Если осталась старая `RecipeVault.app`, после установки можно удалить только этот старый файл приложения. База и модель хранятся отдельно.

Вместо DMG можно скачать ZIP, распаковать его и перенести приложение в «Программы».

Поддерживаются macOS 12+, Apple Silicon и Intel. На macOS 26+ используется Liquid Glass, на более ранних системах — стандартный полупрозрачный материал окна. Приложение с моделью занимает около 1,2 ГБ без каталога.

## Что сохраняется при обновлении

Идентификаторы приложений и пути данных не менялись. При обычной установке поверх предыдущей версии сохраняются рецепты, настройки подключения и уже скачанная модель. Заново загружать ту же модель не нужно.

Перед переносом на другой компьютер удобно сделать копию: **Настройки → Перенос и резервная копия → Экспортировать recipes.json**. На другом устройстве выберите **Импортировать и объединить базу** или настройте синхронизацию.

Системные требования Flutter: [поддерживаемые платформы](https://docs.flutter.dev/reference/supported-platforms).

## Подписи файлов

Это личные сборки: Android подписан постоянным ключом проекта, macOS использует локальную ad-hoc-подпись без нотариализации Apple, Windows-установщик не имеет коммерческой цифровой подписи. Система может показать дополнительное подтверждение запуска.

Файл `Vkusnoteka-1.0.8.sha256` в выпуске содержит контрольные суммы приложений и архива исходников. [Подробности проверок](validation.md)
