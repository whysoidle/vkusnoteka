# Лицензия Вкуснотеки

Исходный код приложения для Android, Windows и macOS, дополнительный сервис импорта, документация и собственные материалы проекта распространяются под **GNU GPL версии 3**. Обозначение: `GPL-3.0-only`. Полный текст находится в [LICENSE](../LICENSE), область действия — в [NOTICE](../NOTICE).

Можно использовать приложение для любых задач, копировать, изменять и продавать его. При передаче приложения или производной версии другим людям нужно соблюдать GPLv3: сохранять уведомления, передавать лицензию и предоставлять соответствующие исходники, включая необходимые скрипты сборки. Изменённые версии нужно обозначать как изменённые и распространять на условиях GPLv3.

Для изменений, которые используются только лично и никому не передаются, публиковать исходники не требуется. Продажа разрешена, но получатели сохраняют право изменять приложение и распространять его дальше.

Сторонние библиотеки, модели и системные компоненты сохраняют [свои лицензии](../THIRD_PARTY.md). Личные рецепты, фотографии, пароли и база пользователя под лицензию приложения не попадают.
