# Локальный ИИ

ИИ помогает превратить свободный текст и субтитры YouTube в ингредиенты и шаги. Разбор выполняется на вашем устройстве. Для обычного каталога и просмотра сохранённых рецептов модель не нужна.

## Включить

1. Откройте **Настройки → Локальный ИИ**.
2. Нажмите **Скачать модель** и дождитесь проверки файла.
3. Оставьте **Использовать локальный ИИ** включённым.
4. Отправьте рецепт или ссылку YouTube в чат.

Модель скачивается отдельно один раз. После прерывания нажмите «Скачать модель» снова — приложение попробует продолжить загрузку с сохранённой части. Готовая модель сохраняется при обычном обновлении приложения.

## Какая модель используется

| Платформа | Модель | Размер скачивания | Движок |
| --- | --- | --- | --- |
| Android и macOS | Qwen3 1.7B INT4 | 977 МБ | Google LiteRT-LM |
| Windows x64 | Qwen3 4B Q4_K_M | 2,50 ГБ | llama.cpp, CPU |

Для Android нужны Android 8+ и ARM64, для Mac — macOS 12+, для Windows — Windows 10 1903+ или Windows 11. На Windows рекомендуется от 8 ГБ оперативной памяти. Для загрузки оставьте хотя бы 1,5 ГБ свободного места на Android/Mac и 3,5 ГБ на Windows.

Android-приложение с моделью занимает около 1,14 ГБ, macOS — около 1,2 ГБ. На Windows используется более крупная модель: вместе с приложением около 2,6 ГБ. Каталог и фотографии занимают дополнительное место.

Движки уже подключены к приложениям. Устанавливать Python, Ollama или получать токен Hugging Face для этих моделей не нужно.

## Что происходит с YouTube

Приложение получает описание и доступные субтитры, затем ищет в них рецепт. Ингредиенты могут быть только в субтитрах — описание с готовым списком не обязательно.

Если в видео несколько рецептов, приложение пытается разделить их на отдельные карточки. Длинные субтитры разбираются по частям. Полученные количества и шаги проверяются по исходному тексту; неизвестные количества отмечаются для проверки.

Если субтитров нет или YouTube не даёт их получить, ИИ не сможет услышать видео самостоятельно. Можно вставить текст вручную или сохранить карточку со ссылкой и заполнить её позже. Распознавания аудио в приложении пока нет.

## Нужен ли интернет

Для скачивания модели, открытия сайта и получения субтитров — да. Сам разбор уже полученного текста выполняется локально. Модель и её файлы не синхронизируются через Яндекс Диск; на каждом устройстве их нужно скачать отдельно.

Если вы настроили дополнительный сервис импорта и отключили локальный ИИ, текст может отправляться на этот сервис. [Настройка сервиса для разработчиков](building.md#дополнительный-сервис-импорта)

## Проверка результата

Перед сохранением просмотрите ингредиенты и шаги. ИИ может ошибаться, особенно в автоматических субтитрах и неясно произнесённых количествах. Отметки проверки помогают заметить такие места; приложение не должно дописывать неизвестное количество за автора.

В настройках есть раздел **Правила точного разбора**, где описаны используемые проверки. Подробности моделей и Windows-движка доступны в [техническом отчёте](release-1.0.6.md). Источники загрузки, точные размеры и контрольные суммы закреплены в [коде загрузчика](../app/lib/services/local_model_store.dart).
