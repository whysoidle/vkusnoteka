# Распознавание YouTube — 1.0.1

Приложения Android, Windows и macOS получают общую версию 1.0.1+11. Формат каталога и файл модели не меняются. Python-сервис остаётся версии 1.0.0.

## Исправления

- macOS: C API LiteRT-LM принимает JSON содержимого системного сообщения и сам добавляет роль. Раньше приложение передавало целый объект сообщения: инструкция оказывалась вложенной и пропадала при формировании ChatML. Теперь передаётся JSON-строка с корректным экранированием. Добавлена нативная регрессия для этого контракта. Поведение API проверено по [исходному коду LiteRT-LM 0.18.0](https://github.com/google-ai-edge/LiteRT-LM/blob/v0.18.0/c/conversation.cc#L353).
- Общий разбор: короткие строки автоматических субтитров объединяются в связные фрагменты. Модель получает одну нумерацию строк; тайм-коды сохраняются в исходнике и извлечённых шагах. Перекрытие фрагментов начинается с границы строки или слова.
- Название ингредиента проверяется по процитированному тексту с учётом обычных русских окончаний. Кухонная утварь не становится продуктом. Неподтверждённые позиции отбрасываются с замечанием.
- Количества, произнесённые словами, сравниваются с цифрами; полные названия граммов, миллилитров и ложек сопоставляются с сокращениями. Явно названное число яиц сохраняется без добавленной моделью единицы «шт.». Неподтверждённое количество остаётся неизвестным.
- Опубликованные отдельные списки продуктов в описании YouTube сохраняются в разных карточках с исходными количествами. Модель извлекает шаги, не переписывая эти списки. Уникальные пропорции и явные номера рецептов ограничивают допустимую привязку фрагмента; общие количества сами по себе не выбирают вариант.
- При нескольких записях шагов для одной карточки действия объединяются. При ошибке модели, отсутствии субтитров или установленной модели отдельные списки продуктов и ссылка остаются в черновиках.

## Если ингредиентов в описании нет

Приложение передаёт субтитры локальному ИИ для извлечения продуктов и действий. Описание не требуется. Продукты, количества, время и порции проверяются по исходным строкам. Если нет и доступных субтитров, аудио автоматически не транскрибируется: сохраняется ссылка и карточка для ручного заполнения.

Локальный LiteRT-LM подключён на Android ARM64 и macOS. На Windows общий парсер, формат карточек и обработка описания обновлены; модель LiteRT-LM для Windows этим выпуском не добавляется. Для разбора свободной речи на Windows нужен настроенный сервис импорта с ИИ и отключённый локальный разбор.

## Проверка

Реальные описание и автоматические субтитры получены для указанного пользователем [видео](https://www.youtube.com/watch?v=AwFPY1vrlsY). Нативный тест использует тот же RecipeModelJob, LiteRT-LM 0.18.0 и Qwen3 1.7B INT4, что приложение. Полный текст видео не включён в исходники; регрессионные примеры синтетические.

Окончательный прогон: 6 фрагментов готовки, две карточки. Первый вариант — 6 опубликованных ингредиентов и 10 извлечённых шагов; второй — 7 ингредиентов и 8 шагов. Количества из описания сохранены без изменений. Исходная версия на этой ссылке в основном возвращала ошибки текста, замечания и пустые списки. Полнота и точность всех шагов не гарантируются этим сравнением.

Проверка без описания отдельно выполняется на субтитрах и коротком синтетическом рецепте. Нативный контракт системного сообщения проверяется с русским текстом, переносами строк, кавычками, обратной косой чертой, emoji, пустой строкой и JSON-подобным текстом.

148 Flutter-тестов и семь проверок нативных контрактов прошли; анализатор без замечаний. В полном прогоне с VM Service освобождены все отслеживаемые контроллеры для вариантов Android, Windows и macOS. Новая обработка локальной моделью реально выполнялась на macOS; нативный Android-прогон на телефоне и Windows-сборка в этой среде не выполнялись.

Модель и автоматические субтитры могут ошибаться. Сохранение корректной структуры не доказывает безошибочность всех действий: карточки нужно проверить по видео, особенно при нескольких рецептах и переходах между ними.

## Установка

- macOS: `dist/RecipeVault-macOS-1.0.1.dmg`. Закройте старую версию и замените приложение в Applications. Каталог и скачанная модель остаются в прежнем хранилище.
- Android: `dist/RecipeVault-Android-1.0.1.apk`, установка поверх прежней версии с той же подписью.
- Windows: `dist/RecipeVault-Source-1.0.1.zip` и `scripts/build-windows.ps1`. Готовый EXE на macOS не собирался.

Размер модели не увеличен: приложение с ней остаётся меньше 2 ГБ без растущего каталога и системных данных.
