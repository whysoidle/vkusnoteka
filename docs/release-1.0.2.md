# Вкуснотека 1.0.2

Приложение получило название **«Вкуснотека»** и выбранную иконку — стеклянную книгу с зелёной закладкой (вариант №4).

## Оформление

- Название и логотип обновлены в общем интерфейсе Android, Windows и macOS.
- Android: новое имя в меню приложений; PNG для Android 7, адаптивная иконка с отдельными слоями для Android 8+, монохромный знак для системных тематических иконок Android 13+.
- macOS: новое имя в Finder, Dock, меню приложения и окне; прозрачные углы и стеклянная книга во всех системных размерах. DMG и ZIP содержат `Вкуснотека.app`.
- Windows: название окна, описание EXE, установщик, ярлыки и иконка ICO с размерами 16–256 пикселей. Установщик удаляет только известные ярлыки прежнего названия; папки с данными не удаляет.
- [Мастера и промпты](../app/branding/README.md) подготовлены встроенным image_gen. `scripts/make-app-icons.py` создаёт системные размеры через macOS `sips` и упаковывает PNG в ICO; повторная генерация не требует обращения к ИИ.

## Совместимость обновления

Версия приложения — `1.0.2+12`. Идентификаторы Android `ru.recipevault.recipe_vault`, macOS `ru.recipevault.app`, Windows AppId, имена внутренних исполняемых файлов и пути хранения сохранены. Облачная папка по умолчанию остаётся `/RecipeVault`.

В Windows поле ресурса `ProductName` намеренно остаётся `Книга рецептов`: его используют `path_provider_windows` и `flutter_secure_storage_windows` для папок базы, настроек, модели и зашифрованных паролей. Пользовательское имя задают `FileDescription`, заголовок окна и установщик. Это исключает создание пустой книги из-за переименования.

На macOS изменены отображаемые `CFBundleDisplayName`/`CFBundleName`; системный путь поддержки определяется неизменным Bundle ID. Android обновляется поверх прежней установки благодаря прежнему Application ID и сертификату. Формат базы и модель ИИ не менялись.

Для обновления Android установите APK поверх предыдущего. На Mac закройте прежнее приложение, скопируйте `Вкуснотека.app` из DMG в Applications; после установки можно перенести старый `RecipeVault.app` в Корзину, сохранив данные приложения. Повторно скачивать модель не требуется.

## Доступность сборок

Android APK и универсальное macOS-приложение собираются на текущем Mac. Исходники Windows, ICO, установщик Inno Setup и сценарий сборки обновлены; Windows EXE здесь не собран и работа установщика на Windows не проверялась.
