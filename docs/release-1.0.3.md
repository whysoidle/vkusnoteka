# Вкуснотека: оформление macOS 1.0.3

Обновление делает окно и навигационные панели заметно прозрачнее и добавляет глубину стеклянным поверхностям. Изменения оформления ограничены macOS; общий импорт, синхронизация и интерфейсы Android/Windows сохраняют прежнее поведение.

## Изменения

- Нативное окно больше не объявляется непрозрачным и использует прозрачный фон. Общая альфа окна остаётся равной 1: текст, фотографии и кнопки не становятся бледными.
- На macOS 26+ используется `NSGlassEffectView.Style.clear` над `NSVisualEffectView` с материалом `underWindowBackground` и смешиванием `behindWindow`. На macOS 12–25 сохраняется системный материал без недоступного API Liquid Glass.
- Нативная Aqua/Dark Aqua автоматически следует эффективной теме Flutter: при переключении темы стекло не остаётся с прежним светлым или тёмным оттенком.
- Уменьшена заливка общего фона и боковой панели, панели действий и импорта. Добавлены тонкая градиентная кромка, светлые отражения и мягкая тень снаружи. Размытие применяется только к крупным навигационным панелям, без отдельного фильтра на каждую карточку каталога.
- macOS-карточки используют полупрозрачную тему вместо жёстко заданного непрозрачного цвета. Приветствие и сообщения чата также имеют более лёгкую заливку; текст остаётся полноцветным.
- У страниц настроек и редактора защитная заливка непрозрачна в первом кадре, затем исчезает за время появления содержимого. После перехода нативное стекло видно и на этих страницах.
- Системное «Уменьшение прозрачности» заменяет фон сплошным и убирает Flutter-размытие. «Уменьшение движения» завершает анимации сразу; обе настройки учитываются на лету.

## Обновление

macOS: версия `1.0.3`, build `13`; установить `Вкуснотека.app` из DMG поверх 1.0.2 после закрытия приложения. Bundle ID, пути базы, пароли и локальная модель сохранены.

Android APK остаётся выпуском 1.0.2; повторная сборка Android/Windows для изменения macOS-оформления не нужна. Архив исходников 1.0.3 содержит условные изменения macOS и общую версию проекта.

## Проверки

- Все **148 тестов Flutter прошли**, `flutter analyze` без замечаний. Девять проверок macOS-интерфейса и сохранения поведения Android/Windows прошли также отдельно.
- Расширены существующие проверки: нативной стороне передаются light/dark при смене темы; первый кадр новой страницы непрозрачен, после анимации защитная заливка исчезает и предыдущая страница не возвращается.
- Системные Reduce Transparency/Reduce Motion проверены на лету; при уменьшении прозрачности Flutter-фильтры отключены. Повторены 150 переходов экранов: все отслеживаемые контроллеры освобождены после GC.
- AppKit-изменения скомпилированы для arm64 и x86_64. Подпись приложения после извлечения из ZIP и контрольные суммы проверены; DMG проверен через `hdiutil verify`.
- Flutter-превью находятся в `docs/previews/macos-light.png` и `macos-dark.png`: они показывают Flutter-слои с альфа-каналом; нативное преломление и размытие рабочего стола в widget-тестах не воспроизводятся.

DMG — **90 087 715 байт**, ZIP — **80 736 190 байт**. Установленное macOS-приложение с прежней моделью — **1 193 553 171 байт**, меньше 2 ГБ без растущего каталога и системных данных.
