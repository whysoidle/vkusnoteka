# Вкуснотека: мягкое размытие фона macOS 1.0.5

На macOS 26+ общий нативный слой Liquid Glass переключён с `clear` на `regular`, чтобы фон за окном имел мягкую матовость. Само содержимое Flutter не фильтруется: текст и фотографии сохраняют чёткость. На macOS 12–25 остаётся системный `NSVisualEffectView`.

Ровные полупрозрачные заливки без диагональных полос, прокрутка каталога под закреплённой шапкой и размытие под ней сохранены. Нативная тема следует выбранной светлой/тёмной теме, ограничения прозрачности macOS учитываются системой. Оформление Android/Windows и формат данных не менялись.

## Проверки

- `flutter analyze` без замечаний; 11 проверок интерфейса macOS и сохранения поведения Android/Windows прошли.
- Проверены прокрутка под шапкой на трёх размерах окна, пиксели Flutter-размытия в двух темах, ограничения прозрачности/движения и сохранение черновиков.
- Изменение относится к нативному стилю материала. Последний полный набор из 150 тестов с GC-проверкой памяти прошёл для 1.0.4; Dart-код приложения с тех пор не менялся.
- Нативная матовость рабочего стола не воспроизводится во Flutter widget-превью: проверяется сборка AppKit для обеих архитектур, а не скриншот рабочего стола в тестовом рендерере.

## Обновление

macOS **1.0.5**, build **15**: закройте приложение и замените «Вкуснотека.app» через DMG. Bundle ID, база, настройки и скачанная модель сохранены. Android APK остаётся 1.0.2; Windows EXE не собирался.

Подпись приложения после извлечения из ZIP, архитектуры arm64/x86_64, метаданные, целостность DMG и SHA-256 проверены. Приложение с моделью — **1 193 553 171 байт**, меньше 2 ГБ без растущего каталога и системных данных.
