# Вкуснотека 1.0.6 — локальный ИИ на Windows

В Windows x64 встроен CPU-движок llama.cpp b11429. Для локального распознавания не нужны отдельные Python-сервисы, Ollama или ввод адреса сервера. В настройках появился раздел «Локальный ИИ»: скачать, остановить/продолжить загрузку, удалить модель, включить/выключить разбор. Изменения применяются сразу.

Windows использует официальную Qwen3 4B Q4_K_M, 2 497 280 256 байт (около 2,50 ГБ); модель скачивается отдельно от установщика. Рекомендуется от 8 ГБ оперативной памяти и 3,5 ГБ свободного места. Для Android/macOS остаётся прежняя Qwen3 1.7B INT4 и LiteRT-LM, общий размер с моделью меньше 2 ГБ. Модель не попадает в базу рецептов или облачную синхронизацию. URL привязан к конкретной ревизии; после загрузки проверяются размер и SHA-256.

## Правила разбора

Windows использует общие правила, схемы JSON и проверку по исходнику с Android/macOS. Инструкции настроены отдельно для каждой модели: для Qwen3 1.7B сохранён проверенный прежний вариант, а для 4B добавлен явный пример продукта без измеренного количества. Количество проверяется рядом с названием ингредиента и не заимствуется у соседнего продукта в той же строке. Неизвестные количества остаются неизвестными. Посуда, включая ложки и ёмкости, отбрасывается. Шаги берутся из подтверждённых строк исходника в исходном порядке. Ингредиенты нескольких опубликованных рецептов сохраняются раздельно и дословно, а схема каждого фрагмента ограничивает допустимые номера рецептов. Явный переход к следующему рецепту разделяет даже короткие субтитры на разные фрагменты. Конец длинного видео не отбрасывается; повреждённый или усечённый фрагмент требует проверки. Исходный текст и ссылка сохраняются при ошибке или отмене.

Параметры Windows: контекст 8192 токена, максимум ответа 2048 токенов на фрагмент, temperature 0, top-k 40, top-p 1, min-p 0, seed 42. Используется тот же ChatML с закрытым пустым блоком thinking, что на других платформах. История разных фрагментов не объединяется. Эти параметры уменьшают произвольность ответа, но не гарантируют безошибочное распознавание; карточку нужно проверять.

## Ресурсы и упаковка

Движок запускается на время импорта, слушает `127.0.0.1` на свободном порту и требует новый случайный ключ для каждого запуска. Соединение обходит системный HTTP-прокси. Вес модели читается из локального файла; автоматическая загрузка движком выключена. Ответ ограничен по размеру и времени.

Windows создаёт процесс приостановленным, добавляет в Job Object с `KILL_ON_JOB_CLOSE` и затем запускает. Отмена, ошибка, завершение импорта и закрытие окна освобождают процесс, модель, сетевой клиент и нативные handles. Аварийное завершение приложения тоже закрывает job и его дочерние процессы. Поздняя отмена старого задания не завершает новый импорт.

`scripts/build-windows.ps1` скачивает закреплённый официальный CPU-runtime, проверяет SHA-256, включает сервер, DLL, Visual C++ runtime и лицензии в `LocalAI` внутри установщика и portable ZIP. Идентификаторы и пути к базе/паролям сохранены.

В исполняемый файл движка встроен манифест `activeCodePage=UTF-8`: без него Windows теряла русские символы в аргументе пути к модели. Исправление действует только для этого процесса, системная локаль не меняется. Локальный ИИ требует Windows 10 версии 1903 или новее; Windows 11 поддерживается. См. [описание Microsoft](https://learn.microsoft.com/en-us/windows/apps/design/globalizing/use-utf8-code-page).

## Проверки

GitHub Actions дополнительно собирает и запускает нативный тест жизненного цикла Windows-процесса и проверку настоящей модели через общий Dart-декодер. Проверяются русские аргументы, отмена, закрытие и повторное освобождение handles, четыре ингредиента с точными количествами и неизвестным количеством молока, время и порции, отдельные карточки двух рецептов и исключение рекламы.

[Сборка Actions](https://github.com/whysoidle/vkusnoteka/actions/runs/37987056030) из commit `7a20dd15536a7a393a223e31ac18ffdbd7d9f6f8` успешно завершена. Прошли 158 тестов Flutter, 23 теста Python, анализатор, нативный тест жизненного цикла процесса и полный разбор настоящей Qwen3 4B на Windows CPU. Проверка запускает модель из русской папки с пробелами. Артефакт `Vkusnoteka-Windows-AI-Validation` содержит запросы и ответы модели.

Установщик — 28 845 872 байта, portable ZIP — 44 207 312 байт, распакованное приложение — 103 000 380 байт. Приложение вместе с моделью — 2 600 280 636 байт. Скачанные пакеты проверены по SHA-256 и CRC, составу DLL и лицензий, UTF-8-манифесту, архитектуре x64, версии и прежнему идентификатору хранилища.

Ручная проверка окна приложения на физическом Windows-компьютере не выполнялась. Общие исправления включены в исходники для трёх ОС; готовые Android/macOS-пакеты пока остаются версиями 1.0.2/1.0.5 соответственно. [Полный отчёт](validation.md).
