# Вкуснотека 1.0.7 — прокрутка и управление на компьютере

Android, Windows и macOS используют единый номер версии `1.0.7` и build `17`. Формат базы, идентификаторы приложений, пути данных и модели ИИ сохранены. Общие проверки рецептов из 1.0.6 теперь входят и в готовые Android/macOS-пакеты.

## Windows и macOS

У настроек, редактора, карточки рецепта, импорта документа и режима готовки область прокрутки занимает всю ширину страницы. Колёсико и вертикальные жесты работают над пустыми боковыми полями, отступами и текстом; ширина содержимого остаётся удобной для чтения. Иконка рядом с «Добавить рецепт» использует основной цвет текущей темы и приглушённый фон. Оформление Android сохранено.

Горизонтальный свайп пальцем или трекпадом переключает каталог и чат, а в режиме готовки — предыдущий/следующий шаг. Свайп вправо на вложенной странице возвращает назад. Короткое или преимущественно вертикальное движение не меняет экран. Горизонтальные фильтры сохраняют своё управление даже у края списка; инерция колёсика не вызывает несколько переходов подряд. Выделение текста мышью работает как раньше. Переходы сохраняют текст чата и работающие таймеры; свайп за последним шагом не закрывает готовку.

Сочетания доступны на уровне приложения, включая настройки, карточку, импорт, редактор и готовку:

- macOS: `⌘N` / `⌥N` — новый рецепт, `⌘F` / `⌥F` — поиск.
- Windows: `Ctrl+N` — новый рецепт, `Ctrl+F` — поиск.

Из главного экрана поиск фокусирует поле каталога. Из вложенной страницы открывается отдельный поиск поверх неё: несохранённый редактор остаётся на месте. Повторное сочетание в поиске фокусирует уже открытое поле. Удержание клавиши не создаёт пачку окон нового рецепта.

## Проверки и сборки

Добавлены проверки пустых областей пяти страниц, жестов трекпада и сенсорного ввода, вертикальной прокрутки, границ горизонтальных фильтров, инерции, выделения мышью, глобальных сочетаний и сохранения состояния чата/редактора/таймеров. Они выполняются отдельно для Windows и macOS. Результаты сборок фиксируются в [отчёте](validation.md).
