# Вкуснотека 1.0.8

В этом обновлении улучшен пересчёт ингредиентов. Версия одинакова на Android, Windows и macOS: **1.0.8**, сборка **18**.

[Скачать приложения](https://github.com/whysoidle/vkusnoteka/releases/tag/v1.0.8) · [Как обновить](installation.md)

## Количества в разных форматах

Раньше строки с запятой, например `Куриный бульон, 800 мл`, могли остаться без пересчёта. Теперь поддерживаются количество перед названием и после него, разные разделители, скобки и запись без пробела между числом и единицей.

| Было | При удвоении порций |
| --- | --- |
| Куриный бульон, 800 мл | Куриный бульон, 1600 мл |
| 800мл бульона | 1600мл бульона |
| Сливки 20% (100 мл) | Сливки 20% (200 мл) |
| Мука 1½ стакана | Мука 3 стакана |
| Яйца 1–2 шт. | Яйца 2–4 шт. |
| Мука двести пятьдесят граммов | Мука 500 граммов |
| Томаты 2 банки по 400 г | Томаты 4 банки по 400 г |

Понимаются десятичные числа, обычные и типографские дроби, диапазоны и распространённые русские числительные, включая `два с половиной`, `поллитра` и `полкило`. Малые количества больше не округляются до сотых: `0,01 г` при уменьшении порций вчетверо становятся `0,0025 г`.

## Что сохраняется

Проценты жирности, температура, время и явно указанный размер отдельной упаковки остаются прежними. Значения «по вкусу» и неизвестные количества не дописываются. Неоднозначные числа могут потребовать ручного уточнения.

Пересчёт всегда использует исходный рецепт. Кнопка **Исходные порции** восстанавливает оригинальные строки, включая слова, дроби и пробелы. Названия и единицы не склоняются автоматически.

## Установка

Скачайте APK для Android, EXE для Windows или DMG для Mac. Для Windows и macOS также есть ZIP-архивы. Устанавливайте поверх предыдущей версии: данные и уже скачанная модель сохраняются при обычном обновлении. [Подробная инструкция](installation.md)

Модели ИИ загружаются отдельно из настроек. Их нет внутри установщиков.
