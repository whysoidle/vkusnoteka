# Вкуснотека 1.0.8 — пересчёт ингредиентов

Android, Windows и macOS используют общий пересчёт и номер версии `1.0.8`, build `18`.

В предыдущей версии строка `Куриный бульон, 800 мл` не пересчитывалась: разбор ожидал тире, двоеточие или число в начале строки. Теперь количество определяется по единице измерения и положению в записи. Поддерживаются количество перед названием и после него, запятая, двоеточие, точка с запятой, тире, знак равенства, перенос строки, скобки и запись без пробела между числом и единицей.

| Исходная запись | При удвоении порций |
| --- | --- |
| Куриный бульон, 800 мл | Куриный бульон, 1600 мл |
| 800мл бульона | 1600мл бульона |
| Сливки 20% (100 мл) | Сливки 20% (200 мл) |
| Мука 1½ стакана | Мука 3 стакана |
| Яйца 1–2 шт. | Яйца 2–4 шт. |
| Мука двести пятьдесят граммов | Мука 500 граммов |
| Мука два с половиной стакана | Мука 5 стакана |
| Томаты 2 банки по 400 г | Томаты 4 банки по 400 г |

Поддерживаются десятичная точка и запятая, разделение тысяч пробелами, обычные, смешанные и типографские дроби, диапазоны с общей единицей, распространённые русские числительные, `поллитра` и `полкило`. Дробные результаты выводятся с точностью до шести знаков после запятой; это позволяет уменьшать небольшие количества без прежнего округления до сотых. Числительные преобразуются в цифры, текст названия и единицы сохраняется без автоматического изменения падежей.

Пересчитывается число упаковок, а явно указанный вес или объём каждой остаётся прежним: `по`, `×`, `массой`, `весом`, `объёмом` или `каждая` в скобках. Проценты жирности, температура, время, соотношения `1:1`, номера сортов, порядковые номера строк и известные числовые названия продуктов сохраняются. Значения «по вкусу» и отсутствующие количества не придумываются. Неоднозначные числа без контекста единицы или количества могут остаться без изменения: произвольное число в названии нельзя надёжно отличить от количества одним форматированием.

Каждое изменение порций использует исходные ингредиенты; накопления округления нет. Сброс восстанавливает исходные строки, в том числе слова, дроби и пробелы. Запись в базе и синхронизация исходного рецепта не меняются.

Проверки включают исходные семь ингредиентов из сообщения, разные форматы и защищённые атрибуты, изменение/возврат/сброс порций в карточке отдельно для трёх ОС. Результаты сборок и проверки готовых пакетов фиксируются в [отчёте](validation.md).

Выпуск собран для всех трёх ОС. Локально и на CI прошли 183 теста Flutter и анализатор; на CI — 23 теста Python, нативный Windows-тест и настоящее распознавание моделью. Android подписан прежним сертификатом; macOS — универсальная сборка с проверенной ad-hoc-подписью. Версии готовых пакетов, целостность архивов и контрольные суммы проверены. Ручная проверка на физическом Windows-компьютере не выполнялась.
