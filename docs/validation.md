- Нативный Windows-тест в итоговом CI прошёл: 12 запусков/остановок, русские аргументы, кавычки, пути с пробелами, отмена с проверкой номера задания и завершение дочернего процесса при уничтожении владельца. - На Mac CPU проверены настоящие Qwen3 4B GGUF и Qwen3 1.7B LiteRT-LM. Windows-тесты дополнительно проверяют отдельную схему каждого фрагмента, закрытие HTTP-клиента, отмену, сбой/тайм-аут процесса и отказ принимать усечённый ответ за полный.

- Полный разбор настоящей Qwen3 4B на Windows CPU прошёл через общий Dart-декодер: четыре ингредиента, точные количества, неизвестное количество молока, время и порции, отдельные шаги двух рецептов и исключение рекламы. Запросы и ответы скачаны из артефакта `Vkusnoteka-Windows-AI-Validation`; повторная локальная проверка этих ответов прошла.
- Скачаны и проверены SHA-256 установщика и portable ZIP, CRC архива, PE32+/x64 приложения, Flutter и локального движка, Visual C++ runtime, лицензии, UTF-8-манифест, версия 1.0.6, бренд и прежнее техническое поле `ProductName` для путей данных. Весов модели в установщике нет.

- Ручная проверка окна приложения на физическом Windows-компьютере не выполнялась. Android APK остаётся 1.0.2, macOS — 1.0.5; общие изменения для трёх ОС входят в исходники 1.0.6.

## Выпуск 1.0.0

Проверено 9 октября 2026 года. **133 теста Flutter и 23 теста Python прошли**, `flutter analyze` без замечаний. APK 1.0.0 (versionCode 10) подписан прежним сертификатом; macOS DMG/ZIP 1.0.0 содержат универсальное приложение Apple Silicon и Intel. Подписи, контрольные суммы и целостность архивов проверены.

- Общие исправления времени жизни HTTP-запросов, изолятов, обработчиков отмены и синхронизации включены во все три платформы. Android очищает обработчики при закрытии Activity, Windows ограничивает OCR-процесс, macOS освобождает временные объекты после фрагментов ИИ.
- Проверено 150 открытий/закрытий экранов: настройки, редактор, карточка рецепта, импорт документов, готовка. Штатные проверки leak_tracker прошли. Прямая полная GC через Dart VM освободила все 5971 / 6381 / 6921 отслеживаемых слабых ссылок на контроллеры в вариантах Android / Windows / macOS соответственно; число ссылок не следует считать числом уникальных объектов.

## Анимации macOS 0.4.2

Проверено 9 октября 2026 года. 124 теста Flutter прошли, `flutter analyze` без замечаний. Интерфейсные изменения ограничены macOS; формат базы, импорт, синхронизация и локальная модель не менялись. Android APK остаётся версией 0.3.2.

- Панель импорта плавно расширяется из боковой области в отдельную страницу. Анимация размера начинается с текущего кадра при быстром обратном переключении. Состояние чата, текст и фокус сохраняются при смене вкладок и ширины окна. Проверены промежуточные размеры, быстрое переключение, сужение окна во время анимации и ⌘ F из импорта.
- Навигация плавно меняет фон выделения, заголовок появляется с затуханием. Карточки реагируют на наведение и нажатие; смена избранного и раскрытие фильтров анимированы. Фото сохраняет тот же ImageProvider и State при наведении и клике. Нажатие «В избранное» не открывает карточку.
- Страницы настроек, редактора и просмотра рецепта заменяют предыдущую страницу сразу. Содержимое появляется с небольшим сдвигом и затуханием за 260 мс на непрозрачном фоне. Регрессионная проверка первого кадра подтверждает отсутствие прежней страницы, непрозрачность фона и промежуточную прозрачность только нового содержимого в обеих темах. Возврат остаётся мгновенным.
- Нативный канал передаёт «Уменьшение движения» и «Уменьшение прозрачности» при запуске и при изменениях системных параметров. Учитывается также MediaQuery.disableAnimations. Проверено включение уменьшения движения во время раскрытия панели: движение заканчивается сразу, без потери состояния. Переходы страниц и масштабирование отключаются; размытие отключается независимо.
- Дополнительные проверки Android и Windows подтверждают отсутствие macOS-виджетов анимаций в их интерфейсах. Общие тесты импорта, WebDAV, базы, тем, прокрутки, фотографий и таймеров прошли.

- Универсальная release-сборка 0.4.2 (arm64 + x86_64) собрана в отдельном каталоге. Подпись вложенных библиотек проверена; после повторной сборки обновлена подпись верхнего пакета с сохранением прав sandbox. Размер установленного приложения без повторного подсчёта символических ссылок — 216 436 404 байт; с моделью — 1 193 620 436 байт, меньше 2 ГБ без растущего каталога и системных данных. DMG, ZIP и контрольные суммы проверяются перед передачей. Физическая оценка плавности анимаций пользователем ещё не выполнена.

## Исправления интерфейса macOS 0.4.1

Проверено 9 октября 2026 года. 119 тестов Flutter прошли, `flutter analyze` без замечаний. Изменения поведения интерфейса ограничены macOS; общая логика базы, импорта и синхронизации не менялась. Проверки Android и Windows также прошли.

- В широком окне действие «Импорт рецепта» раньше оставляло каталог и чат на прежних местах, меняя только заголовок. Теперь открывается отдельная область чата, поле ввода получает фокус. Каталог возвращает прежнее представление. Проверены ширины 1380 и 1000, состояние чата и введённый текст сохраняются.
- Стандартный переход Cupertino сдвигал прозрачную страницу настроек поверх предыдущей. Для macOS страницы теперь заменяются сразу. Тест проверяет первый кадр открытия и закрытия настроек в светлой и тёмной теме, без ожидания завершения анимации. Переходы Android и Windows сохраняют свои прежние настройки.
- Universal release собирается в отдельной рабочей папке, чтобы не менять пакет уже открытого приложения и не прерывать работу пользователя. Установочный DMG и ZIP имеют версию 0.4.1; для обновления нужно закрыть приложение и заменить его в Applications. Каталог и параметры подключения хранятся отдельно от пакета.

## Перенос на macOS 0.4.0

Проверено 9 октября 2026 года на macOS 27.0.1, Apple Silicon, Xcode 27.0 и Flutter 3.47.6. Универсальная release-сборка содержит arm64 и x86_64; физический запуск проверен на Apple Silicon. Минимальная версия macOS — 12.0. Android APK остаётся проверенной версией 0.3.2; формат базы не менялся.

- 117 тестов Flutter прошли, `flutter analyze` без замечаний. Новые проверки подтверждают фильтры боковой панели, горячие клавиши, сохранение состояния чата при изменении ширины окна, смену темы и отключение размытия при уменьшении прозрачности.
- Три нативных XCTest прошли внутри приложения: окно с Flutter и стандартными кнопками, запись/чтение/удаление синтетического пароля в login Keychain, русский OCR через Apple Vision внутри sandbox из кеша, используемого Flutter; проверено отклонение постороннего пути. Пользовательские пароли и аккаунт Яндекс не использовались.
- Размер установленного .app: 213,679,217 байт; с моделью: 1,190,863,249 байт — меньше 2 ГБ без каталога и системных данных. Веса скачиваются отдельно; в установщике их нет.
- Приложение реально запущено: Flutter использует Metal Impeller; нативные PDFium и LiteRT-LM встроены, динамические зависимости разрешаются. Подпись проверена `codesign --verify --deep --strict`.
- Локальная Qwen3 1.7B реально выполнила разбор русского текста через тот же Swift/C мост LiteRT-LM 0.18.0, который используется в приложении.
