# Вход в Яндекс Диск

С версии 0.3.1 основной способ — [WebDAV с паролем приложения](yandex-webdav.md), без регистрации OAuth-клиента. Ниже инструкция для сохранённого прежнего способа OAuth. Яндекс может требовать верификацию разработчика через Госуслуги.

Один раз зарегистрируйте OAuth-приложение под своим аккаунтом на https://oauth.yandex.ru/client/new.
Название: «Книга рецептов». Выдайте только чтение и запись файлов Яндекс Диска: `cloud_api:disk.read`, `cloud_api:disk.write`.

Адреса Redirect URI:

```
recipevault://oauth
http://localhost:9876/auth
```

Для платформы Android, если форма запрашивает параметры приложения:

- Пакет: `ru.recipevault.recipe_vault`.
- SHA-256 сертификата личного APK: `9A:D4:F6:C5:0C:15:02:1B:F8:D5:C4:5F:DF:99:C4:CB:7C:4B:51:E7:3D:1D:0D:C1:F4:3E:05:FB:30:8A:BD:F1`.

Скопируйте только публичный Client ID. В приложении откройте **Настройки → Яндекс Диск → Настройка подключения**, вставьте Client ID. Настройка сохраняется автоматически. Нажмите **Войти в Яндекс Диск**, подтвердите доступ в браузере. На втором устройстве используйте тот же Client ID и аккаунт.

Кнопка входа использует код авторизации, PKCE S256 и проверку `state`, без встроенного секретного ключа. Токен и refresh-токен сохраняются в защищённом хранилище, вне общей базы. Перед синхронизацией просроченный токен обновляется. Для Windows используется браузер и временный локальный обработчик callback на порту 9876.

В сборках для распространения Client ID можно задать при сборке: `--dart-define=YANDEX_CLIENT_ID=...`; тогда пользователю потребуется только кнопка входа. В этой личной сборке Client ID пока отсутствует: его должен выдать Яндекс после регистрации. Авторизация с реальным аккаунтом не выполнялась.

Официальное описание PKCE и получения токена: https://yandex.ru/dev/id/doc/ru/codes/code-url.
