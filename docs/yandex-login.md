# Прежний способ входа через OAuth

Для нового подключения используйте [WebDAV с паролем приложения](yandex-webdav.md). Этот раздел оставлен для существующих OAuth-подключений и разработчиков собственных сборок. В готовом выпуске Client ID не задан.

## Если OAuth уже был настроен

Действующее подключение поддерживается после обновления. Можно оставить его или перейти на WebDAV в **Настройки → Яндекс Диск → Способ подключения**.

## Для собственной сборки

Вам потребуется зарегистрированное приложение Яндекс OAuth с публичным Client ID. Условия регистрации и проверки аккаунта задаёт Яндекс; смотрите текущую форму регистрации в [кабинете OAuth](https://oauth.yandex.ru/).

Параметры подключения, используемые кодом проекта:

| Параметр | Значение |
| --- | --- |
| Разрешения | `cloud_api:disk.read`, `cloud_api:disk.write` |
| Redirect URI | `recipevault://oauth` |
| Локальный callback на компьютере | `http://localhost:9876/auth` |
| Android package | `ru.recipevault.recipe_vault` |

Если форма запрашивает SHA-256 сертификата, возьмите отпечаток того ключа, которым подписан ваш APK. Отпечаток чужой сборки для собственного ключа не подходит.

Введите публичный Client ID в **Настройки → Яндекс Диск → Настройка подключения**, затем нажмите **Войти в Яндекс Диск** и подтвердите доступ в браузере. Для собственной сборки Client ID также можно задать через `--dart-define=YANDEX_CLIENT_ID=...`.

Приложение использует PKCE S256 и проверку `state`; секретный ключ клиента в него не встраивается. Токены хранятся в защищённом хранилище устройства вне общей базы. Код подключения: [yandex_auth.dart](../app/lib/services/yandex_auth.dart).

Реальная OAuth-авторизация с аккаунтом пользователя в отчёте выпуска не проверялась.
