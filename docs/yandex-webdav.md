# Подключение Яндекс Диска через WebDAV

В версии 0.3.1 WebDAV — основной способ подключения. Регистрация OAuth-приложения, Client ID и подтверждение разработчика через Госуслуги не требуются.

По актуальной справке Яндекса WebDAV доступен пользователям с тарифом Яндекс 360. Убедитесь, что ваш тариф включает эту возможность: https://www.yandex.ru/support/yandex-360/customers/disk/web/ru/webdav.

1. Откройте Яндекс ID → **Безопасность → Доступ к вашим данным → Пароли приложений**.
2. Создайте пароль типа **Файлы WebDAV**, например с названием «Книга рецептов Android». Основной пароль аккаунта не подходит. Пароль приложения показывается один раз.
3. Установите APK поверх предыдущего, затем откройте **Настройки → Яндекс Диск**. Выберите **WebDAV · пароль приложения**, если ранее использовали OAuth.
4. Введите логин Яндекса и созданный пароль. Поля сохраняются автоматически; кнопка сохранения не нужна.
5. Нажмите **Проверить подключение**. Проверка читает свойства Диска и не меняет рецепты. Затем нажмите **Синхронизировать**.
6. На Windows выберите тот же аккаунт и папку `/RecipeVault`. Для каждого устройства можно создать отдельный пароль WebDAV того же аккаунта. Общая база останется одной.

Адрес сервера фиксирован: `https://webdav.yandex.ru`, порт 443. Пароль хранится в защищённом хранилище устройства, не попадает в `settings.json`, экспорт или общую базу. Логин и путь папки хранятся в локальных настройках. Учётные данные не передаются по перенаправлениям HTTP.

Автоматическая синхронизация работает после изменений и каждые 3 минуты, пока приложение открыто. После сбоя нажмите **Повторить**. При отсутствии доступа сообщение предлагает проверить пароль и тариф. **Отключить Диск** удаляет пароль подключения с этого устройства, сохраняя локальные рецепты; пароль можно отозвать в Яндекс ID.

Формат и путь базы не изменились: `/RecipeVault/recipes.json`, служебные копии устройств — `/RecipeVault/.devices/*.json`. Все три платформы объединяют правки по версиям записей. Сначала файл полностью загружается под временным именем, затем публикуется методом MOVE. При повреждённой облачной базе синхронизация останавливается. Незавершённые файлы `.upload` не участвуют в объединении; после прерывания процесса они могут остаться в папке и их можно удалить вручную.

Предел общей базы — 20 МБ, включая фотографии. Рецепты остаются доступны офлайн. Вес локального ИИ не загружается на Диск.

Действующие OAuth-подключения сохраняются при обновлении; их можно переключить на WebDAV. Для новой или ещё не подключённой установки WebDAV выбирается автоматически. Исходники Windows обновлены, установщик необходимо собрать на Windows. С настоящим аккаунтом синхронизация пока не проверена: пароль пользователя в среде разработки отсутствует.
