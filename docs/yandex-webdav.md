# Одна книга на всех устройствах

Вкуснотека хранит рецепты на устройстве и может синхронизировать их через Яндекс Диск. На телефоне и компьютерах используйте один аккаунт и одну папку. Собственный сервер не нужен.

Основной способ подключения — **WebDAV с паролем приложения**. Регистрировать OAuth-приложение и получать Client ID не требуется. По [справке Яндекса](https://yandex.ru/support/yandex-360/customers/disk/web/ru/webdav), этот доступ входит в тарифы Яндекс 360.

## Настроить первое устройство

1. В [Яндекс ID](https://id.yandex.ru/) найдите **Безопасность → Доступ к вашим данным → Пароли приложений**.
2. Создайте пароль типа **Файлы WebDAV**. Назовите его, например, «Вкуснотека — телефон».
3. Скопируйте выданный пароль: позже Яндекс его не покажет.
4. Во Вкуснотеке откройте **Настройки → Яндекс Диск** и выберите **WebDAV · пароль приложения**.
5. Укажите логин Яндекса и этот пароль. В поле **Папка базы** оставьте `/RecipeVault`.
6. Нажмите **Проверить подключение**, затем **Синхронизировать**.

Настройки сохраняются автоматически. Нужен именно пароль приложения, обычный пароль аккаунта не подходит.

## Подключить телефон или другой компьютер

Повторите настройку в приложении на втором устройстве: тот же аккаунт и папка `/RecipeVault`. Для него можно создать отдельный пароль WebDAV. После синхронизации появится общий каталог.

Android, Windows и macOS используют один формат базы. Если на каждом устройстве уже были свои рецепты, при синхронизации они объединятся.

## Когда появляются изменения

При включённой автоматической синхронизации приложение обменивается изменениями после правок, при возвращении в приложение и каждые три минуты, пока оно открыто. Для немедленного обмена нажмите кнопку облака или **Синхронизировать** в настройках.

Без интернета рецепты остаются доступны локально. Если соединение не удалось, сообщение в настройках подскажет причину; после исправления нажмите **Повторить**. Закрытое приложение не выполняет синхронизацию в фоне.

Если один рецепт независимо изменили на двух устройствах, сохраняются обе версии. Одна будет подписана «копия при конфликте» — сравните их и оставьте нужное.

## Где лежат данные

Основной файл — `/RecipeVault/recipes.json`. Рядом есть служебная папка `.devices` с копиями устройств: она помогает объединить изменения при одновременной работе. Не удаляйте её для «очистки» каталога.

Фотографии входят в базу; общий предел файла — 20 МБ. Модели ИИ, пароли и настройки оформления в облако не загружаются.

Пароль хранится в защищённом хранилище ОС. Кнопка **Отключить Диск** убирает подключение на текущем устройстве, сохраняя локальные рецепты. Сам пароль при необходимости можно отозвать в Яндекс ID.

Существующие OAuth-подключения продолжают поддерживаться. Для новых установок выбран WebDAV; прежний способ описан [отдельно](yandex-login.md).

## Если подключение не получилось

Проверьте логин, пароль приложения, доступ к WebDAV в вашем тарифе и одинаковую папку на устройствах. Подробнее — в [ответах на частые вопросы](troubleshooting.md#не-подключается-яндекс-диск).

Поведение объединения проверяется автоматическими тестами. Проверка синхронизации с настоящим аккаунтом пользователя в отчёте выпуска не проводилась.
